# MediSlot – Healthcare Appointment Management System

MediSlot is a web-based healthcare appointment management system developed using React.js. It provides separate portals for patients, hospitals, and doctors to manage healthcare appointment-related activities through a single application.

## Features

### Patient Portal

* Patient registration and login
* Search hospitals and doctors
* Filter doctors by specialization and department
* View doctor information, ratings, reviews, experience, consultation fees, and available slots
* Book appointments
* Reschedule appointments
* Cancel appointments
* View appointment history
* Manage patient profile

### Hospital Portal

* Hospital registration and login
* Manage hospital profile
* Manage departments
* Manage doctors
* View and manage appointments

### Doctor Portal

* Doctor login
* View appointments
* Manage schedule
* Manage availability

## Technology Stack

* **Frontend:** React.js
* **Programming Language:** JavaScript (ES6+)
* **Markup:** JSX, HTML5
* **Styling:** CSS3
* **Build Tool:** Vite
* **Data Persistence:** Browser LocalStorage
* **Version Control:** Git and GitHub
* **Development Environment:** Visual Studio Code

## React Concepts Used

The project demonstrates several React and JavaScript concepts, including:

* Component-based architecture
* JSX
* `useState`
* `useEffect`
* Props
* Event handling
* Conditional rendering
* Forms and validation
* Array methods such as `map()` and `filter()`
* JSON data handling
* Browser LocalStorage
* CRUD-like operations

## How to Run Locally

### Prerequisites

Install:

* Node.js
* npm
* A modern web browser

### Installation

Clone the repository:

```bash
git clone https://github.com/Kaniska957/MediSlot.git
```

Navigate to the project directory:

```bash
cd MediSlot
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Data Storage

The current prototype uses **Browser LocalStorage** for client-side data persistence.

The application stores information such as:

* Patient accounts
* Hospital accounts
* Doctor accounts
* Hospital and department information
* Appointments
* User sessions

No external database is required to run the current prototype.

## Project Scope

MediSlot currently focuses on frontend-based healthcare appointment management. The application demonstrates the core workflows of patients, hospitals, and doctors within a single React.js application.

The current version does not include a centralized backend database, server-side authentication, real-time queue management, payment processing, online consultation, or AI-based waiting-time prediction.

These features can be considered for future development.

## Future Enhancements

Future versions of MediSlot can include:

* Backend and centralized database integration
* Secure server-side authentication and authorization
* Real-time appointment and queue management
* AI-based waiting-time prediction
* Appointment reminders and notifications
* Online consultation
* Payment integration
* Hospital analytics and reporting
